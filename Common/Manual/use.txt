JUSTTERMINAL MANUAL, USING IT

This is the first part, about using the terminal. The second part is
about writing your own programs, manual programming opens it.

Up and down arrows or page up and page down move through this text,
so do 8, 2, 9 and 3 on the numpad or the top row. 7 and 1 go to the
start and the end. esc or q closes it.


STARTING

Click the terminal button on the bottom bar to open it.
It only takes the keyboard after you click inside it. While it has the
keyboard the game's keys don't work, click somewhere else to give them
back. Esc closes it.

Type a command and press enter. help lists the commands, help and a
command name shows what it does with examples, like help graph.

Tab finishes what you are typing, a command name, a colonist or a
file. Press it twice to see everything that fits.

Names with spaces use _ instead, like pawn Red_Tasca.

Keys on the prompt:
  up, down          the commands you typed before
  page up/down      scroll back through what was printed
  ctrl+l            clear the screen, same as clear
  ctrl+c            drop what you are typing
  ctrl+u            erase everything before the cursor
  ctrl+a, ctrl+e    to the start or the end of the line
  ctrl+plus/minus   text bigger or smaller


THE WINDOW

The little light on the top of the frame pins the window. Pinned, it
stays open when you click the map or open other tabs and you can drag
it around. Click it again, or type pin, to put it back on the bottom bar.

A- and A+ next to it change the text size, font 18 does the same and
font reset puts it back.

reset place puts the window back in its first place and size. If you
use JustDesktop, a right click on its taskbar button does the same.

  pawns       everyone with mood, health and what they're doing

PIPES, WATCH AND ALIAS

| sends what a command writes through a filter:

  pawns | grep Sleeping        only the lines with Sleeping
  factions | grep -v hostile   the lines without hostile
  history | head 5             the first 5 lines
  cat ~/log | tail 3           the last 3
  idle | wc                    how many lines

watch runs a command again every few seconds, space runs it right
away and q stops:

  watch pawns         every 2 seconds
  watch 10 danger     every 10 seconds

alias gives a command line a short name, the same in every game:

  alias sick checkup        sick runs checkup
  alias who pawns | grep    who Tasca runs pawns | grep Tasca
  alias                     lists them
  unalias sick              removes one


RIMTOP

rimtop, or top, is a colony monitor like btop. Mood, temperature and
wealth graphs, power and weather, the stock, and the colonists listed
like processes.

  up, down     pick a colonist
  enter        their details, click works too
  left, right  the pages of the details: mood, health, skills, gear, work
  s            change the sort
  r            reverse it
  tab          all four boxes, or one of them on the whole screen
  1 to 4, 0    one box, or all of them
  q            quit

On the power screen up and down scroll the list of buildings.


GRAPHS

graph alone lists what it can draw.

  graph temp           temperature, 3 days back and 1 ahead
  graph temp 7 2       7 days back and 2 ahead
  graph mood Tasca 3   Tasca's mood the last 3 days
  graph wealth 30      wealth the last 30 days

Wealth, colonists and raid points come from the game's own history.
Mood and food are kept by the mod, one value each hour in your save,
so those start from when you added the mod.


EDIT MODE

The normal commands only read. Type edit to go into edit mode, the
screen turns red and the commands there change your colonists. Type
help there to see them, exit leaves.

  group miners Drill Wolf Kovul   make a group
  group                           list the groups
  ungroup miners                  remove one
  work Tasca                      Tasca's work priorities
  work @miners mining 1           mining 1 for everyone in miners
  work all research 0             nobody researches
  medicine all herbal             herbal medicine or worse for everyone
  area Tasca home                 Tasca only goes in home
  policy Drill food               Drill's food policy
  policy @miners food lavish      lavish food for the miners
  role Tasca moral_guide          opens the ritual to change her role
  exile Drill                     asks to banish Drill
  caravan                         the towns close by
  caravan Tifunni                 opens the caravan window, route set
  draft @guards                   drafts the guards
  undraft all                     everyone back to work
  schedule Tasca                  her 24 hours from midnight
  schedule @night wwwwwwssssssssawwwwwjjjj
                                  s sleep, w work, j joy, a anything,
                                  m meditate, one letter an hour
  schedule @night nightshift      sleeps 10 to 18
  schedule all reset              back to the game's start


STORAGE

storage lists every stockpile zone and storage building with its room
and priority. What one takes can be kept and put on others:

  storage save 3 meals          keeps what 3 takes in ~/storage/meals
  storage apply meals shelves   every shelf takes the same
  storage apply meals kitchen   the ones in kitchens
  storage apply meals 5         only 5, zones and all work too

apply changes things, so it's for edit mode. The file is plain text,
nano can change it: hitpoints, quality and one thing on each line.
Things a shelf can't hold are left out when it's applied there.
Linked shelves are one entry, with the link's name, since the game
has them share what they take.

Who can be a name, @ and a group, or all.


FILES

You can keep notes and programs in the terminal. They are kept in the
save, nothing goes on your computer. ~ is your folder.

  ls [folder]       what's in a folder
  cd notes          into a folder, cd .. one up, cd alone back to ~
  mkdir notes       make a folder
  cat todo          show a file
  nano todo         write a file
  cp todo todo2     copy a file
  mv todo done      rename or move
  rm todo           remove a file or folder, it asks first if the
                    folder has things in it

In nano: arrows move, ctrl+s saves, ctrl+k erases a line, ctrl+x or
esc quits and asks first if something isn't saved. With num lock off
the numpad moves too, like the arrows printed on it, with num lock on
it types numbers.

less shows a file without changing it, like this manual.

A file can be 64 KB and there can be 500 files and folders.

CRON SCRIPTS

A file that ends in .cron is a small script that checks something
every few hours and does something when it's true. nano lowfood.cron
starts one with an example.

  every 2h
  fire daily
  if /stock/food < 3
  action letter only {value} days of food left

every is how often it checks, like 1h, 6h or 2d. Instead of every a
script can have when, then it runs the moment something happens:

  when raid     enemies show up on one of your maps
  when arrive   someone from outside shows up: traders, visitors,
                raiders, wanderers, one event for each of them
  when downed   a colonist goes down
  when break    a colonist has a mental break
  when sick     a colonist gets a disease
  when death    a colonist dies
  when letter   a letter arrives
  when trader   traders show up

In those {who} is who it happened to and {event} what happened, like
the disease, the letter's name or trader from Rope Confederation.

While a when script runs, /event has the pawn it happened to: name,
kind, faction, hostile, gender, age, genes, xenotype and traits. So a
script can look at that one pawn:

  when arrive
  fire each
  if /event/genes has "fire spew"
  action letter {who} has fire spew, {event}

has is true when the text has the word anywhere in it, it's good for
lists like genes and traits. cron test shows the /event lines as only
there when it happens.

fire is each (every time it passes), daily (once a day at most) or
once (it fires and turns itself off).
Then the if lines, all of them have to pass.
Then one action, with the commands to run. ; runs more than one.

In an if, * stands for every folder there, like /pawns/*/mood < 25.
The ifs compare with < > <= >= = != or has.
In the action {value} is the first if's value, {name} and {names} who
matched the *, {count} how many, and a path in {} reads that path.

A cron script can't have loops, for that write a program and run it
from the action.

  cron                    every script, on or off, last time it fired
  cron lowfood on         turn it on, it checks at the next hour
  cron lowfood off
  cron lowfood every 6h   changes the every line for you
  cron raid when raid     makes it a when script
  cron lowfood fire once
  cron lowfood test       each if with what it reads now
  cron_edit               the same with keys: up, down, enter on/off,
                          left, right every (or when), f fire,
                          t test, e edit

example lists cron scripts and programs to start from, example
raid.cron copies that one to ~/examples. Turn it on with cron raid on,
change it with nano.

notify hello shows a message at the top left, letter hello a letter on
the right. Those are the usual actions.

A script with a mistake shows as bad and can't be turned on. One that
breaks while running, like when a colonist it names is gone, turns
itself off and leaves a message saying why.


MOD OPTIONS

mod_options opens them. There you can:
  pick the colors or make your own theme
  make each screen effect stronger, weaker or turn it off
  pick another font, an installed one or a file in the fonts folder
  change the text size, the welcome text and the prompt
  set commands to run when the terminal starts, like fetch
  give the commands your own names
  keep the normal color in edit mode
  not save anything from this mod in the save, and delete what this
  game has
  export the files and programs of this game, and import them into
  another one. Exports go in JustTerminal/Exports in the game's save
  folder, named after the colony. Importing adds them to what the game
  has, a file with the same name is replaced and cron scripts come in
  turned off

To take the mod out of a playthrough, turn saving off and save first.
